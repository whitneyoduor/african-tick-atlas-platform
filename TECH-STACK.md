# African Tick Atlas — Full Tech Stack & Platform Documentation

**Project:** African Tick Surveillance Atlas (ATSA) — an ICIPE continental geospatial surveillance platform
**Repo:** github.com/whitneyoduor/african-tick-atlas-platform
**Deployment:** Vercel (static frontend) · Railway (optional backend)

---

## 1. High-Level Architecture

```
┌────────────────────────────────────────────────────────────────────┐
│  FRONTEND (React 18 + Vite 6, static SPA)                         │
│  src/  →  built by `vite build`  →  dist/  →  deployed on Vercel  │
│                                                                    │
│  API layer: src/app/lib/api.ts                                    │
│    - PRODUCTION ("static mode"): reads pre-built JSON/GeoJSON     │
│      directly from /public — NO live backend required             │
│    - DEVELOPMENT: proxies /api → local Express (port 3001)        │
│      with graceful fallback to static JSON if the API is down     │
└──────────────┬─────────────────────────────────────────────────────┘
               │  public/ assets (committed)
┌──────────────▼─────────────────────────────────────────────────────┐
│  DATA LAYER (static assets, all deployed on Vercel)               │
│  occurrences.json · epidemiological.json · map-points.json         │
│  genbank/ · rc-data/ · health/ · febrile-choropleth.geojson       │
└──────────────┬─────────────────────────────────────────────────────┘
               │  generated by build/export scripts
┌──────────────▼─────────────────────────────────────────────────────┐
│  DATA PIPELINE (dev-only, regenerates public/)                    │
│  Raw sources (Excel/CSV/TIFF/GPKG/GBIF/NCBI)                      │
│    → server/src/import.ts + scripts/ + server/src/scripts/        │
│    → SQLite (Prisma: server/prisma/tickatlas.db)                  │
│    → static JSON/GeoJSON in public/                               │
└────────────────────────────────────────────────────────────────────┘
```

**Key insight:** the deployed site is a **fully static app**. All data is pre-computed and committed under `public/`. The Express + Prisma + SQLite backend exists for the data pipeline and optional live API, but the website itself works with zero backend calls (static mode).

## 4. Page-by-Page Description

### 4.1 MAPS (`/`) — MapPage + TickMap
- **Purpose:** Interactive continental map of tick occurrence points across Africa.
- **Data:** `public/map-points.json` (9,656 African-country-verified points, ~370 KB) + `epidemiological-meta.json` for filter lists.
- **Six view layers:** Tick Occurrence (teal) · Species Richness (indigo) · Host Diversity (amber) · Associated Diseases (pathogen color-coded) · Prevalence (disease-present sized dots) · Density (heatmap).
- **Filters (right panel + top bar):** species (searchable type-ahead), disease, country, host, collection method, year range; active-filter chips color-coded per dimension; key-species quick pills (R. appendiculatus, R. sanguineus, R. microplus, H. marginatum, H. rufipes).
- **Interactions:** hover → pointer; click → popup (species, host, disease, country, year); result count badge; disease legend.
- **Export:** PNG capture of the map canvas.
- **Basemap:** OpenFreeMap "liberty", Africa bounds `[-25,-40]→[55,40]`.

### 4.2 TRENDS (`/trends`)
- **Purpose:** How African tick surveillance has changed over time.
- **Data:** full `public/epidemiological.json` (client-side).
- **Filters:** species, country, year range (from/to inputs synced to a Recharts **Brush**).
- **5 clickable stat cards:** Total Records, Tick Species, Animal Hosts, Diseases Found, Countries (click to switch the main metric).
- **Main chart:** gradient-filled **AreaChart** over years.
- **Six donut charts:** Records by Country · Tick Vectors · Animal Hosts · Pathogens · Sampling Methods · Records by Decade.
- **Export:** PNG of the area chart.

### 4.3 FEBRILE (`/febrile`) — FebrilePathogens + ChoroplethMap
- **Purpose:** Human febrile-illness pathogens that present like malaria, mapped by genus.
- **Data:** `epidemiological.json` (filtered African) + `public/febrile-choropleth.geojson` (ADM1 polygons with per-genus counts).
- **Classification:** records bucketed into 6 genera — Rickettsia, Borrelia, Babesia (**core febrile**); Coxiella, Anaplasma, Ehrlichia (**other neglected febrile**).
- **Summary cards:** two category summaries (core / other) with chips; 5 stat cards (Core / Other / Total records, Tick Vectors, Countries).
- **Panels:** Records by Genus donut · Category Split donut · Genera Covered list.
- **Choropleth map:** quantile-binned red scale, layer filter (All/Core/Other/genus), hover popup with per-genus counts, point counts, unmapped-points notice.
- **6 clickable genus cards** (2×3) that set the map filter.

### 4.4 TICK SPECIES (`/species` + `/species/:name`)
- **List (SpeciesList):** "X species documented across Y countries". Top-15 species donut with clickable slices → `/species/:name`; per-species GenBank stats chips; 4 bar charts (Records by Country, Animal Hosts, Associated Diseases, Records Over Time).
- **Detail (SpeciesPage):** species name header, 4 stat cards (Epi Records, Countries, Hosts, Diseases); **GenBank section** — sequences/genes/countries/avg-length stats, gene filter, 4 dashboard cards (Gene Distribution, Molecular Data by Country, Hosts, Sequence Length by Gene), **clustered GenBankMap** (hover popup, click-to-zoom, red species-centroid marker), sortable/searchable/paginated GenBank table (NCBI accession links); epidemiological charts (3 donuts + time bar).

### 4.5 DISEASES (`/diseases` + `/diseases/:name`)
- **List (DiseaseList):** "X pathogens detected in ticks across Y countries". Category toggle (All / Febrile / Other neglected febrile); 80-pathogen browse grid with color dots + febrile badges; selecting a pathogen shows geographic distribution map (EvidenceMap), 3 donuts (Tick Vectors, Animal Hosts, Records by Country), Records Over Time donut, 5 stat cards.
- **Detail (DiseasePage):** 4 stat cards; **Geographic Distribution** clustered map; custom **Timeline Heatmap** (country × year density grid, teal ramp); 4 donut charts (Vectors, Country, Hosts, Over Time).

### 4.6 TICK COHORT Rc (`/environmental`) — ReproductivePotential
- **Purpose:** Cohort reproductive potential (Rc) model output 2025 at ADM2 resolution.
- **Data:** `rc-data/index.json` + `rc-data/countries/{gid}.json` + `rc-data/geo/{gid}.json` (GADM ADM2 boundaries).
- **Filters:** Country, Species (4: A. variegatum, H. marginatum, R. appendiculatus, R. microplus), Month.
- **Map:** plasma-like Rc color ramp, hover info card (ADM2 + Rc), bottom legend, "No data" overlay.
- **Seasonal Rc LineChart:** 12-month mean with reference line at selected month.
- **Stats panel:** Peak Month · Annual Mean · Persistence (months/12) · Peak Rc. Plus "About this model" explainer.

### 4.7 CLIMSYNOPTICK (`/climsynoptick`) — HealthAccess + HealthMap
- **Purpose:** Synoptic country/district dashboard combining 9 health, livestock, and environmental metrics.
- **Metrics:** cattle · goat · sheep · population · mammal richness · malaria · health facilities · tick records · pathogen records.
- **Data:** `health/livestock-choropleth.geojson` (6,501 districts) + `livestock-countries.geojson` (50 countries) + `facilities.geojson` (100k points, sub-Saharan census + HOT/OSM North Africa).
- **Map:** choropleth with natural-break (quantile) color ramp, **missing data shown grey (never 0)**, hover popup listing all 9 metrics, click to pin, country focus fly-to, facet coloring (e.g. per facility class or tick species).
- **Controls:** 5 metric selector cards, layer/species/country/facility dropdowns, country-focus bar, **district profile panel** (all metrics + focus/unpin), **data-coverage audit** (per-metric coverage% + missing countries), sortable "Highest countries" table, 5 facility-class cards.
- **Footer:** full source attribution (FAO, UNFPA, IUCN/MAP, facility census, GBIF, atlas pathogens).

### 4.8 REFERENCES (`/references`)
- **Purpose:** Source literature behind the atlas. Built from parsed `epidemiological.json`.
- **Features:** GBIF citation card (DOI 10.15468/dl.jve6v3), keyword search (title/DOI/country/species), show all/fewer toggle, per-reference record-count badges and DOI links.

### 4.9 ABOUT (`/about`)
- **Purpose:** Platform overview. Uses `occurrences-meta.json` + `epidemiological-meta.json` for stats.
- **Sections:** Overview · Citation (CC-BY 4.0) · Platform Features (3×3) · Data Sources · Contact/Support (GitHub).

## 6. Database Schema (SQLite via Prisma)

**Occurrence** (`occurrences`): `id`, `gbifId` (unique), `species`, `latitude`, `longitude`, `country`, `year`, `citation`.
**EpidemiologicalRecord** (`epidemiological_records`): `id`, `species`, `yearOfStudy`, `yearStart`, `yearEnd`, `country`, `title`, `links`, `epidemiologicalDisease`, `methodOfExtraction`, `relatedHosts`, `epidemiologicalIncidences`.
**GenBankRecord** (`genbank_records`): `id`, `accession` (unique), `species`, `organism`, `gene`, `sequenceLength`, `definition`, `taxonomy`, `collectionDate`, `country`, `location`, `latitude`, `longitude`, `host`.

### Current data volumes
- Occurrence records: **167,109** globally (year range 1839–2026); **10,354** are African-country-verified points on the map (Europe/Middle-East records in the source GBIF download are intentionally excluded)
  - Enriched on top of the source download with `scripts/fetch_gbif_africa.py` (+2 live GBIF records), `scripts/fetch_inaturalist_africa.py` (+288 iNaturalist observations) and `scripts/fetch_africa_ticks.py` (a full GBIF order-Ixodida sweep of all 54 African countries plus an iNaturalist harvest of 32 major tick taxa → **+720 real records**, mostly Amblyomma hebraeum +120, North-African Ixodes/Haemaphysalis/Dermacentor records, Hyalomma truncatum +23, Amblyomma marmoreum +18, A. variegatum +14, H. dromedarii +10, R. evertsi +9). A back-to-back full sweep proves the five key species are exhausted: `R. sanguineus` (524 mapped points), `R. appendiculatus`, `R. microplus`, `H. marginatum`, `H. rufipes` already hold every coordinate-bearing African record GBIF and iNaturalist publish for them, so no new points were fabricated or duplicated. A handful of African countries still have no georeferenced records in any public repository (e.g. Niger, Chad, Western Sahara for R. sanguineus); those are shown from literature/presence data instead of fabricated coordinates.
- Epidemiological records: **12,212** (11,348 source records, replicate-normalized to 80 clean disease names so each disease detail page returns data)
- Diseases/pathogens: **80** · Tick species: **236** · Hosts: **354** · Countries: **50** admin units (6,501 districts)
- GenBank: **145 species**, ~10,414 records
- Health facilities: **100,133** mapped (98,745 sub-Saharan census + 3,738 HOT/OSM North-Africa; 2,350 dropped for no/bad coordinates), merged into a single `facilities.geojson`
- Febrile map: 10,701 disease points → 10,315 mapped to ADM1 across 50 countries (countries with zero mapped points — Niger, Chad, Côte d'Ivoire, Eritrea, Equatorial Guinea, Sierra Leone, São Tomé — render in the zero shade with their partition boundaries via the all-countries iris in `build-febrile-choropleth.cjs`, so the map stays seamless and honest)

## 8. Deploying

### Frontend (Vercel)
- `vercel.json`: all routes SPA-rewritten to `index.html` except `/genbank/*`; `/genbank/*` and `/rc-data/*` served with 1-hour cache + permissive CORS.
- Build: `vite build` → `dist/` (static).
- **No env vars needed** — static mode is automatic in production builds (`USE_STATIC = !import.meta.env.VITE_API_URL && import.meta.env.PROD`).

### Backend (Railway, optional)
- `server/railway.json`: Nixpacks build (`pnpm install && prisma generate`), start `tsx src/index.ts`.
- Env: `PORT`, `NCBI_EMAIL`, `NCBI_API_KEY` (optional; NCBI rate limits), `CCHF_CSV`.

### Local dev
```
pnpm install
pnpm dev:server    # Express on :3001 (needs a seeded tickatlas.db)
pnpm dev           # Vite on :5173, /api proxied to :3001
pnpm build         # production build
npm run build      # same (npm also works)
```

## 9. Cross-cutting notes & known data caveats

- **Static-first design:** the deployed site serves fully static files; the live API is optional and used only during development.
- **Africa-scoped everywhere:** every page filters to African records only (`AFRICAN_COUNTRIES` set + Africa bbox `lat∈[-35,37], lng∈[-20,55]`).
- **Figure-only exports:** downloads are PNG figures (charts/maps); raw datasets are not downloadable from the site.
- **Data honesty:** states with no real occurrence/coordinate data (e.g. **Niger** febrile coverage, **R. sanguineus** in Libya/Niger/Chad/Western Sahara per GBIF) are left empty rather than filled with fabricated values.
- **Libya** is rendered at ADM1 (22 shabiyas) because GADM has no ADM2 layer; **Western Sahara** has 4 admin regions (recently restored).
- **Record counts:** `epidemiological.json` (12,212) vs `epidemiological-meta.json` `totalRecords` (11,348) — the meta header count reflects the original source-record total; record rows were normalized (split compounds) so each of the 80 diseases in the meta detail view returns its records.
